# Jagnath Sanitaries Website

Premium mobile-first website for Jagnath Sanitaries, Rajkot.

## Run

1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Important files

- `config/site.ts` holds phone, WhatsApp, email, address and Instagram link.
- `config/content.ts` holds website copy, categories, brands and FAQ content.
- `public/photos` is for downloaded Instagram photos.
- `public/videos` is for downloaded Instagram videos.
- `data/raw` stores the raw Apify JSON results.

Do not commit `.env.local` or any API token.
